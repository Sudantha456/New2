# Baseline profile for You-Tube.
#
# A baseline profile is a list of classes and methods that ART should verify and compile ahead of
# time at install time instead of interpreting on first use. For a Compose app it is the single
# highest-leverage start-up optimisation available: Compose's own runtime, the Material theme and
# the first screen's composables are otherwise interpreted during exactly the frames the user is
# watching.
#
# AGP packages this file (src/main/baseline-prof.txt) into the APK as `assets/dexopt/baseline.prof`,
# and `androidx.profileinstaller` (a dependency of this module) installs it on the device.
#
# The rules below are hand-tuned around the app's real start-up path: Application →
# MainActivity → theme → shell → first feed frame → the playback session. They use the standard
# human-readable profile format: HSPL<class-descriptor> or HSPL<class>;-><method>(<args>)<ret>, where
# H = hot, S = startup, P = post-startup and L = the class/method itself.
#
# Producing the *fully* optimal profile needs an on-device run:
#     ./gradlew :app:generateBaselineProfile
# with a device attached, which is why CI also accepts a `baseline-prof.txt` replacement. What is
# listed here covers start-up and the feed scroll path, and is checked in so that even a build with
# no connected device ships a profile.
